# 使用前说明
本文件仅是单阶段指令。先读根目录 `AGENTS.md` 和 `docs/IMPLEMENTATION_PLAN.md`；只执行本阶段，完成后等待审核。详情见 `Northstar_English_Codex_正式开发提示词_V1.md`。

## Prompt 09｜最终集成、质量回归和本地发布

在 Phase 08 验收后进行**最终工程化与回归**。不要在本阶段再增加未经评审的新业务模块。

执行：
1. 建立从零运行的可重复步骤（例如 `./scripts/dev-up.sh` + `./scripts/dev-down.sh`，实际命令按仓库技术栈决定）；脚本安全、幂等、不给现有容器造成干扰。README 包含 Mac 安装前置、版本要求、端口配置、环境变量、数据库迁移、初始化原创课程、备份与恢复、常见故障。
2. 检查依赖版本和构建稳定性，前后端生产 build、lint/typecheck、JUnit/Java 测试、数据库集成测试、Playwright E2E 全部实际运行，附完整命令和失败信息。
3. 浏览器回归在 1440×900 完成：首次打开 → 课程中心 → Demo 01 → 播放第 6 句 → 盲听输入错误 → 显示差异/回听 → 阅读题证据定位 → 录音或合理跳过 → 作文保存两版 → 测验故意答错 → 到期复习 → 关闭/重启 → 恢复学习记录与复习项。
4. 检查边界：无音频、无网络、API 500、数据库重启、麦克风拒绝、快速切句、反复提交、用户输入特殊字符、导出异常、重复初始化、浏览器刷新、无 AI 配置、无权限的目录项不可误进入。
5. 覆盖无障碍基本项（键盘导航、focus、标签、对比度）、HTTP/HTML 安全（XSS、CORS、本地端口绑定、密钥不泄露）、日志隐私、音频对象资源释放。
6. 与原型截图比较布局，任何有意识的设计偏差记录在 `docs/DESIGN_DEVIATIONS.md`；不得无需求重设计 UI。保留 `references/` 为只读参考，不作为生产运行依赖。
7. 给出真实的验收汇总：`PASS`、`PASS_WITH_NOTES`、`FAIL`，逐项列出已通过、手工待测、未完成和影响，不允许全绿造假。检查 `git status`、变更清单，并提交下一阶段路线建议但不开展开发。
