# 使用前说明
本文件仅是单阶段指令。先读根目录 `AGENTS.md` 和 `docs/IMPLEMENTATION_PLAN.md`；只执行本阶段，完成后等待审核。详情见 `Northstar_English_Codex_正式开发提示词_V1.md`。

## Prompt 03｜还原桌面 UI、路由和统一工作台

在 Phase 02 验收后执行，只完成页面层和课程浏览/上下文联动，不提前做复杂 AI 或语音评分。

开发：
1. 用 React/Next.js 组件重建原型视觉（不是把 HTML 放 iframe 或整体使用 `dangerouslySetInnerHTML`），在 1440×900 下与已确认原型相近。布局要求：深色左侧导航约 224px、浅色主区域、右侧助教、底部固定播放器约 76px，内容宽度自适应；小于约 980px 时助教折叠为抽屉。
2. 实际路由：`/dashboard`、`/courses`、`/lesson/[lessonId]`、`/review`、`/reports`、`/settings`；工作台 Tab 为课文、精听听写、精读词汇、口语跟读、写作、课时测验。Tab 状态可使用 URL 查询参数以便恢复与分享本地链接。
3. 首页“继续学习”、课程中心的四册目录、原创 Demo 01 入口使用 Phase 02 的真实 API。未开放目录不能误导为可学习；任何没有真实数据的报告模块显示明确空状态。
4. 工作台共享 `lessonId`、`sentenceId`、当前 Tab、字幕/译文偏好。选句必须更新右侧预置讲解；切 Tab 不丢句子选择和文本草稿。句子讲解在盲听模式下不得透出听写目标文本。
5. 建立可复用按钮、Tab、卡片、消息、空状态、弹窗、Toast、音频组件容器；支持键盘焦点和可读性的语义元素，不因动画丢焦点。
6. 主视觉与逻辑分离，未实现的功能明确标记“下一阶段开发”，按钮不得看似可用但点击无响应。

验收：六个主要页面和六个 Tab 可导航、刷新可恢复页面及上下文、课程页通过真实 API；1440×900 对照截图检查；无水平溢出；错误课次 404/空状态合理；前端 build/lint/Playwright 路由检查通过。写 `PHASE_03.md` 并停止。
