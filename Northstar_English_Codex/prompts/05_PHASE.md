# 使用前说明
本文件仅是单阶段指令。先读根目录 `AGENTS.md` 和 `docs/IMPLEMENTATION_PLAN.md`；只执行本阶段，完成后等待审核。详情见 `Northstar_English_Codex_正式开发提示词_V1.md`。

## Prompt 05｜精读词汇、阅读理解与证据定位

在 Phase 04 验收后执行，只完成阅读/词汇这条垂直链路。

开发：
1. 为 Demo 01 建立至少 5 个原型既有词条（community garden、beside、bench、soil、watering can），每条具有实际源句 ID、语境义、词性或适当说明、示例；收藏状态与已掌握状态分开。
2. 精读 Tab 中点词卡可跳转并高亮原句，同时更新右侧上下文讲解；词汇卡片数据来自 API 而非散落在 React 常量里。
3. 实现原型阅读理解题 `Where should Mia put the small plants?`，答案 `Next to the blue bench.`，提交反馈必须给出第 6 句证据。答错追加阅读 evidence 和对应复习来源，答对也有真实作答记录。
4. 后端保存练习题版本、题目 ID、选项 ID、证据句 ID、尝试结果；前端不使用硬编码题目索引作为持久标识。正确答案是否在响应中提前暴露需根据自学场景设计，至少在用户提交前 UI 不显示。
5. 练习完成需要作答证据；单纯浏览词卡、点击“下一步”不视为已完成。允许用户继续浏览或选择跳过。

验收：错答能够跳到正确证据句并进入复习；刷新后卡片收藏和答题历史保留；重新提交流程不造成非法重复；课程 ID 不匹配时返回明确错误。完成测试、记录 `PHASE_05.md` 并停止。
