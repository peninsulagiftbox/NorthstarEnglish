# Northstar English｜Phase 1 桌面 Web 详细设计与验收规范

> 版本：1.0 · 2026-10-21  
> 面向：单人自学英语的本地优先 MVP  
> 输入依据：《新概念英语》AI 网站竞品与 PRD V1.0、上传参考视频中的逐句精听 + 右侧讲解工作台，以及本轮“第一阶段自己使用、优先桌面 Web、使用原创样例验证”的约束。  
> 本文对应可运行静态原型：`english_lab_desktop_prototype.html`。**原型交互不等于正式 AI、自动发音评分或服务端功能已经实现**。

## 1. 产品北极星和约束

### 1.1 定位

一款以《新概念英语》四册课程框架为未来长期主线的个人英语学习工作台：听得懂、读得懂、说得出、写得出，并通过隔日复习验证是否真正掌握。

**一期明确只验收 1 节原创课从打开到复习的闭环**：降低单人开发成本，避免教材内容版权问题，避免尚未建立真实测量就虚报能力分数。

### 1.2 交付范围

- 单用户、本地运行、无注册与支付。
- 页面层：学习首页、四册课程中心、课内工作台（6 个 Tab）、智能复习、学习报告、个人设置。
- 能力层：合法原创文本 + 合成配音；逐句播放；变速；循环；英文/中文显隐；上下文讲解；精听听写；精读词汇/证据题；麦克风录制/回放；指导式写作/版本留存；测验/错题回流；本地持久化。
- AI 的正式服务端接入列为 **Phase 1 的后半段扩展**，先以规则生成的解释和练习保证页面数据流正确；外部 AI 生成必须加上本课/本句检索上下文与审核边界。

### 1.3 首版不做

- 不收录未经许可的《新概念英语》原文、插画、课文音频；不从第三方站点抓取全套教材。
- 不做官方 CEFR 评定、不凭 ASR 转写给音素/语调评分、不凭一句录音给综合口语分数。
- 不做社区排行、会员支付、多人社交、低延迟多人语音房、3D 虚拟人。
- 不把“打开课文”视为“熟练掌握”；只展示确实记录到的训练证据。

### 1.4 桌面设计原则

- 设计基准宽 1440 px，高 900 px；1220–1440 为缩放过渡；低于约 980 px 折叠右侧讲解区域。
- 侧栏导航约 224 px；主内容可拉伸；课内正文与讲解约 2:1；固定播放器高度约 76 px。
- `focus ring`、英文大字号、足够对比度、简洁固定底栏、键盘快捷键、面板不弹跳。
- 色彩：深海军蓝侧栏、浅灰阅读背景、翡翠绿操作状态，提供清晰的主/次级操作。
- 教学反馈与技术状态必须分离：音频播放失败、录音权限拒绝、题目答错属于不同错误类型。

## 3. 全页面设计规格

### P01 学习首页

**主要问题**：“我现在应该做什么？”

- 顶部标题与轻量说明；主视觉 Hero 为“继续上次课程”；主 CTA“开始/继续学习”。
- 首屏统计：完成练习阶段、到期复习卡、已保存写作版本（这些是行为数据，不叫英语能力得分）。
- “今日学习路径”列出 6 项，状态 `not_started`、`in_progress`、`practiced`、`skipped`。点击进入对应 Tab。
- “今日可用时间”在正式版支持 10、20、30 分钟，可自动选择“快速学习”或“完整精学”。原型先不做时长预测算法。
- 空数据：第一访问引导 Demo 01；有数据：定位到上次 Tab；上次练习失败：显示“继续草稿”。

**验收**：第一次打开 2 次点击内进入可播放课文；刷新页面可以恢复本地写作草稿、复习队列和已练阶段；本地没有证据时不显示虚构百分比。

### P02 课程中心

**主要问题**：“我处于什么课程体系？能学哪一课？”

- 顶部显示四册卡片：第一册 144、第二册 96、第三册 60、第四册（常见 1997 修订版）48；明确目录是课程结构说明，不是免费授权内容库。
- 已具备内容的课程状态 `available`，其他为 `catalog_only`，不能点击进入空白“假课文”。
- 原创示范课独立命名 Demo 01，不冒用某一具体新概念 Lesson 的编号。
- 为未来正式引入版次、配套练习课、知识点、音频与版权元信息预留模型。

**验收**：任何未配置内容的课不会被误标为已上线；不能因为选择第二册就跳出伪造的教材内容。

### P03 课文工作台：统一容器

**主要问题**：“我为什么要在同一课的多个功能之间切换？”

布局草图：

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ Side nav │ 面包屑 / Book 01 / Original Demo                       设置  │
│          ├─────────────────────────────────────────────────────────────────┤
│          │ 课程名 + 目标 + 练习进度                                      │
│          │ [课文] [精听听写] [精读词汇] [口语跟读] [写作] [课时测验]       │
│          ├─────────────────────────────────────────┬───────────────────────┤
│          │ 主学习区域                              │ 右侧上下文句子助教    │
│          │                                         │                       │
│          │ [播放] Mia: Good morning ...           │ 本句原文 + 知识点     │
│          │        早上好……                        │ 用法 / 例句 / 练习    │
│          │ [播放] Leo: Yes, it is ...             │                       │
│          │       ……                               │ 问答区                │
│          ├─────────────────────────────────────────┴───────────────────────┤
│          │ ⏮  ▶  ⏭  正在播放原句    ──────◎────   1.0×  循环    J/Space/K│
└──────────┴─────────────────────────────────────────────────────────────────┘
```

交互：

1. 点击某行的背景：选择该句，更新右侧讲解和当前高亮（正式版可选择是否自动播放）。
2. 点击三角播放：切换到该句并立即播放；播放结束可以继续全文或仅循环一句。
3. 点击☆：收藏该句，并关联 `source_sentence_id` 创建复习卡。
4. 译文/英文显隐独立控制；盲听隐藏英文，右栏默认应同步降低剧透信息（正式版规则；原型当前仍展示助教原文，属于已知限制）。
5. Tab 切换时保留 `lesson_id` 和 `selected_sentence_id`；失去音频焦点时只停止音频，不清除课程状态。
6. 快捷键：`Space` 播放/暂停，`J` 上句，`K` 下句，`R` 循环模式；输入框有焦点时快捷键自动失效。

**已知设计补完**：正式版实现逐句波形、A-B 区间循环、手动校正对齐时间戳、错句定位标记；这些需要真音频时间轴，不能在无时戳音源上假装可用。

### P04 精听听写 Tab

**任务**：先听一句音频，再输入自己听到的英文。

- 10 个句子序号，选中后播放；每次检查仅针对一个 `sentence_id`。
- 听写编辑区；提交前不能见到目标句的正确文字（课文 Tab 允许主动查看，这是学习者自由选择）。
- 判分：原型对大小写、标点容错，其他词汇以简单文本比较作为提示；正式版需最短编辑路径 / WER、插入/遗漏/替换分类，词形错误与同义表达另作处理。
- 结果区：用户原始输入、目标句、可再次播放、加入复习原因。
- “完成阶段”的条件：至少一次非空听写提交；允许错后继续，但不称为已掌握。
- “暂时跳过”允许转入下阶段，状态为 `skipped`，不计作完成。

**异常**：无音频资源 → 禁止进行有效听写；网络中断 → 保留草稿和听写目标；输入空白 → 显示原因，不生成错误数据。

### P05 精读词汇 Tab

**任务**：理解一句英语如何表达真实含义。

- 词汇展示原句、中文含义和本课关联句位置；词句收藏可进入复习队列。
- 初期演示 5 个词组：`community garden`、`beside`、`bench`、`soil`、`watering can`。
- 阅读理解问题必须能指出证据句；回答错误自动引导回课文第 6 句。
- 正式版词典条目应同时提供词性、音标、常见搭配、语境义、例句和词形变化；用户收藏状态独立于课程数据。
- 完成条件：至少完成一题阅读理解，可以错后结束，但需标记错误知识点。

### P06 口语跟读 Tab

**任务**：先听原音，再录制自己的模仿。

- 目标句 + 示范音频 + 下一句；录音按钮清晰显示 idle / requesting_permission / recording / processing / ready / failed。
- 获得授权后用 `MediaRecorder` 录音，本地播放；如果拒绝权限，允许转入其他学习，不强制录音。
- 原型**不做自动识别和评分**；正式版接入 STT 仅做转写对比，若需要音素/语调/流利度，需要专业 pronunciation assessment，不拿 STT 的词匹配率冒充口语评分。
- 录音仅存在当前内存中的 Blob URL；刷新会丢失，正式版要增加用户选择的加密本地存储或服务端保存与删除。
- 完成条件：本次有一段录音可回放；拒绝权限则记 `skipped`。

### P07 写作 Tab

**任务**：在小作文里主动使用所学表达。

- 给定场景与目标语块；用户输入 2–3 句英文，支持保存 V1/V2/V3。
- 原型指导规则：目标句数、是否尝试 `please` / `beside` / `I can`，不声称判断语法正确性。
- 正式版 AI 批改：按 `任务完成度 / 语法准确性 / 用词自然度 / 表达清晰度` 输出有证据的反馈，并请求用户亲自改写；不同版本通过 diff 比较。
- 初次提交前不展示完整范文，避免用户只做抄写。
- 完成条件：保存至少一个非空写作版本。

### P08 课时测验 Tab

**任务**：以新的题目验证理解与表达，而不是只记录点击次数。

- 原型包含 3 道原创选择题；答题前无答案反馈，提交后显示对错与证据句。
- 错误试题关联 `lesson_id + sentence_id + knowledge_point` 写入复习队列。
- 提交后可重做，但要保留历史作答记录（原型仅保留最近状态，正式版必做）。
- 页面不得将 3 道选择题结果称为“听说读写总分”。后续独立设计听辨、口头复述、开放写作证据。

### P09 智能复习

**任务**：跨日重新回忆已经错过的内容。

- 进入方式：从首页“到期卡片”或课程收藏/错误记录入口。
- 卡片正面中文意思；用户先回想英文，再翻开英文答案。
- 自评“还不会 / 记住了”安排下次复习；演示版使用简单的 1 分钟 / 1 天调度，不冒称 FSRS、SM-2 等已完整实现。
- 后续：按练习类型交替使用听辨/拼写/造句/复述；真实难度估计需要多个练习样本。

### P10 学习报告

**任务**：“我到底学了什么，哪方面需要改善？”

- 原型只展示已练习阶段数量、提交作文版本数量、复习卡片数量，不编造语言能力曲线。
- 第二步记录可比较的测量指标：`独立听写正确率`、`阅读证据题正确率`、`复述完整度`、`写作错误复现率`、`延时复测通过率`。
- 在没有足够历史复测数据前，趋势图应该显示“样本不足”而不是填充模拟数据。
- 写清楚指标分母：按句数、按题数、按会话轮次还是按词数，不混用。

### P11 个人设置

- 字幕/译文默认显示策略；播放速度、键盘快捷键帮助、麦克风权限提示。
- 浏览器本地保存与清空；在正式版加导出/导入 JSON、脱敏、密钥隔离和数据备份。
- 单人环境不意味着可以把第三方 API 密钥放前端；模型调用仍应经后端代理管理。

## 4. 原创 Demo 01：The Neighborhood Garden

**内容和教学说明完全为演示项目自行编写，不属于《新概念英语》原文或其官方配套练习。** 音频使用本地语音合成软件从原创文本生成，质量仅用于验证播放、句子切换、跟读流程，不能替代正式语音教材与读音评测音源。

| ID | 说话者 | 原创台词 | 本课教学点 |
|---|---|---|---|
| 01 | Mia | Good morning. Is this the community garden? | 问候，Is this ...? |
| 02 | Leo | Yes, it is. Are you here to help? | 一般疑问句与简短回答 |
| 03 | Mia | I am. My name is Mia. | 自我介绍 |
| 04 | Leo | Nice to meet you, Mia. I am Leo. | 第一次见面 |
| 05 | Mia | Where should I put these small plants? | should + 动词原形 |
| 06 | Leo | Please put them beside the blue bench. | 礼貌请求、地点介词 |
| 07 | Mia | Do they need water now? | Do ... need ...? |
| 08 | Leo | Just a little. The soil is still wet. | 数量、still 的用法 |
| 09 | Mia | I can bring a watering can. | can + 动词原形 |
| 10 | Leo | That would be great. Thank you! | 委婉赞同与感谢 |

配套题目：

- 精听：听出第 6 句并键入整句，容错英文标点与大小写。
- 精读：Where should Mia put the small plants? 答案：Next to the blue bench.
- 跟读：播放第 5 句、录音、回放，自行与示范音比对。
- 写作：Write 2–3 sentences about helping in a garden. Use please, beside, or I can ...
- 测验：地点、花盆摆放位置、礼貌请求句型三道选择题，错误进入复习。

## 5. 数据对象及关键字段

```ts
// 后端正式实体（概念字段，不是已建表承诺）
type ContentLicense = {
  id: string; owner: string; sourceType: 'original'|'licensed';
  rightsScope: string; expiryAt?: string; proofFile?: string;
};
type CourseBook = {id:string; editionId:string; sequence:number; name:string; catalogOnly:boolean};
type Lesson = {
  id:string; bookId:string; title:string; origin:'original'|'licensed';
  licenseId:string; publishStatus:'draft'|'reviewed'|'published';
};
type Sentence = {
  id:string; lessonId:string; sequence:number; speaker?:string;
  text:string; translation?:string; audioAssetId?:string;
  startMs?:number; endMs?:number; contentVersion:number;
};
type StudySession = {id:string; userId:string; lessonId:string; startedAt:string; lastTab:string; lastSentenceId?:string};
type LearningEvidence = {
  id:string; userId:string; lessonId:string; sentenceId?:string;
  skill:'listen'|'speak'|'read'|'write'; eventType:string;
  result:'correct'|'incorrect'|'submitted'|'skipped'|'uncertain';
  attempt:number; detailJson?:unknown; createdAt:string;
};
type ReviewItem = {
  id:string; userId:string; sourceEvidenceId:string; sentenceId:string;
  dueAt:string; memoryState?:unknown; lastResult?:string;
};
type WritingRevision = {id:string; userId:string; lessonId:string; version:number; text:string; createdAt:string};
type AudioAsset = {
  id:string; url:string; createdBy:string; licenseId:string;
  mimeType:string; durationMs:number; sha256:string;

```

**不建议**只建一个 `lesson.is_completed`、一个 `word.is_known`，这样后续无法解释学习成效，也无法从真实错误生成复习计划。  
**特别注意**：学生自己录的音频是用户生成数据，不能与教材音频混在同一种素材授权标签里。

### 建议的 API（正式版本）

| 方法与路径 | 用途 | 最重要的输入/输出 |
|---|---|---|
| `GET /api/books` | 四册目录 | 版次、结构、可用状态 |
| `GET /api/lessons/:id` | 加载一课 | 课程、句子、时间轴、知识点、版权信息 |
| `POST /api/study/events` | 记录学习证据 | 幂等 `eventId`、练习类型、课次与句子 |
| `POST /api/exercises/:id/attempts` | 提交听写/测验 | 标准化结果和错误类型 |
| `POST /api/recordings/presign` | 获得录音上传权限 | 文件大小、Mime、有效期 |
| `POST /api/tutor/messages` | 受约束 AI 答疑 | 当前 lessonId/sentenceId、知识点、回答依据 |
| `POST /api/writing/revisions` | 保存作文版本 | 版本号、原文、可选反馈状态 |
| `GET /api/reviews/due` | 获取到期复习 | 到期、来源、卡片内容 |
| `POST /api/reviews/:id/results` | 复习反馈 | 反馈与下次复习时间 |
| `GET /api/reports/me` | 学习证据汇总 | 分母、正确数、回访表现、样本量 |

### 技术路线

- **当前可点演示**：单个 HTML + 原生 JS + 内嵌原创合成配音 + `localStorage`，无需服务端。录音依赖浏览器麦克风授权，可在 `localhost` 使用。
- **正式个人用 MVP**：Next.js / React / TypeScript + Tailwind + Zustand（前端状态）；Spring Boot 单体服务 + MySQL（内容、作答、复习）；文件可先存本地独立目录，随后升级 OSS/S3；Redis 非必须，出现排队/缓存需要再加。
- **音频**：提供合法原声或合法合成音源，句音对齐需要逐句时间轴；正式支持 AB 循环、变速音调保持、离线缓存。
- **AI**：Spring Boot 代理模型服务，明确凭证不进入浏览器；输出采用受约束 JSON；规则校验 `sourceSentenceIds` 必须属于当前课；为语言事实问题提供可追溯的审核知识或标注即时生成。
- **写作**：文本版本保存与 AI 批改分离。模型不可用时仍可继续写作与储存。
- **口语**：浏览器录音与音频上传解耦，ASR/发音评测异步可恢复；评分服务失败时提供音频回放，不返回编造分数。

## 6. 状态流与异常恢复

```text
课程状态
  not_started
     ↓ 用户打开
  in_progress
     ├── 完成练习 → practiced [存在练习证据]
     ├── 跳过     → skipped   [不视作完成]
     └── 中断     → paused    [保存当前课/句/草稿]

精听听写
  idle → playing → typing → submitted → feedback
                               ├── correct → 记录结果
                               └── incorrect → 记录错误 + 创建复习卡

口语录音
  idle → permission_request → recording → processing → ready
             └── denied → 展示原因 + 提供“跳过/重试”

写作
  draft → save V1 → guided feedback → revise → save V2

复习
  due → recall → reveal → self_rating
                  ├── again → 近期重现
                  └── good  → 推迟复习
```

**离线与容灾原则**：当前本地模型无云同步，因此清除缓存会丢失数据；正式版每个答题事件应带幂等 ID。网络失败先保持本地草稿，再重试，不得无限显示“保存中”。

## 8. 分四个迭代交付

### Sprint 0｜第 1–2 天：课程结构与正版素材边界

1. 冻结 Demo 01 原创内容、标准答案、词汇知识点和授权元信息。
2. 建立 lesson/sentence/media/license 模型；每一句绑定自己的音频或时间戳。
3. 先验证浏览器播放兼容性、音量、按句切换、录音权限。

**完成定义**：能听到 10 句原创音频；查看每句对应文字；不存在未经许可的教材内容。

### Sprint 1｜第 3–5 天：课文工作台与精听

1. 左侧导航、课内 Tab、右侧句子讲解面板、固定播放器。
2. 单句播放、全文继续、速度、循环、字幕/译文显隐。
3. 精听听写与人工可解释差异反馈，生成结构化错误事件。

**完成定义**：答错任意句，能定位回本句并在复习队列看到它。

### Sprint 2｜第 6–8 天：说读写输出

1. 词卡及语境释义、阅读证据题。
2. 浏览器录音与回放；不接发音评分时明确展示限制。
3. 写作草稿、版本记录、提示式检查、任务完成证据。

**完成定义**：一节课走通至少一次听写、理解、跟读录音及写作保存；拒绝麦克风时可以跳过并继续。

### Sprint 3｜第 9–12 天：测验、复习、报告与部署

1. 课时测验、错误关联、复习调度与卡片。
2. 本地进度与学习数据持久化，统计真实完成数量。
3. 统一错误/空状态；基础 Playwright E2E 自动化；本地启动脚本与备份说明。

**完成定义**：完成第一次练习→退出网站→重新打开→恢复草稿和到期复习；测验答错的句子能重新学与再次测。

> 时间均为单人开发的粗略工作量拆解，不是保证工期。复杂正式 AI 及教材许可待后续迭代。

## 9. 下一轮最值得投入的三个产品能力

1. **真正的细粒度精听器**：真实时间轴、句段同步、A-B 循环、音频波形和听写错词定位，保留用户参考视频最强的学习体验。
2. **受约束 AI 教师**：仅基于当前原创课程内容及审核知识回答，讲解有原句依据，错误可追溯，优先解决“讲错课”的致命问题。
3. **学习证据数据模型**：用同一套 `LearningEvidence` 与 `ReviewItem` 串联听力、阅读、口语、写作，而不是四套无法交流的独立工具。

**暂不优先**：3D 头像、排行榜、虚拟积分商城、无依据的英语等级仪表盘。这些容易让网站“看起来功能多”，但不能证明英语学习有进步。

## 10. 静态原型使用说明

文件：`english_lab_desktop_prototype.html`。全部 CSS、JS、课程数据与示范 MP3 内嵌于一个 HTML，适合本地检查交互原型。

- 推荐在 Chrome 中打开；若想测试麦克风录音，建议在文件所在目录开启本地服务：

```bash
cd /path/to/downloaded/file
python3 -m http.server 8000
# 打开 http://localhost:8000/english_lab_desktop_prototype.html
```

- 首页：`开始第一节课` → 点击任意句音频 → 切换 `精听听写`。
- 精听：输入听到的英文 → `检查听写` → 故意错一个词 → 查看复习是否新增卡。
- 精读：点击 `beside` 查看例句 → 阅读问题选择答案。
- 跟读：请求麦克风 → 录音 → 停止 → 回放；如权限不可用，选择“暂时跳过”。
- 写作：写两句英文 → 保存版本 V1 → 修改 → 保存版本 V2。
- 测验：提交 3 道题 → 打开智能复习 → 翻卡并反馈。
- 设置：切换译文 → 返回课程；清空本机数据需要确认。

**特别说明**：生成音频较机械，目的是测试音频相关功能；不适合作为正式发音模仿标准。原型的 AI 面板只是人工编写解释和规则问答演示，**没有后端 AI 模型**。数据仅保存在本浏览器本地，适合产品验证，不适合作为长期唯一备份。
