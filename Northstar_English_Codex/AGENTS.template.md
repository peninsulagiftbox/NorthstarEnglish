# Northstar English｜Codex 工作规则（模板）

> 本文件由项目所有者确认后放在仓库根目录并命名为 `AGENTS.md`。如仓库已有该文件，请合并而不是覆盖。

## 项目目标

- 单用户、Mac 本地优先、桌面 Web 优先，合法原创课程先完成「听、说、读、写、测验、复习」的完整闭环。
- 参考：`references/phase1/english_lab_desktop_prototype.html`、`references/phase1/Northstar_English_Phase1_桌面Web详细设计与验收.md` 与预览图。
- 四册《新概念英语》目前仅目录占位；未经授权不得导入正文/配套音频。

## 实施流程

1. **先计划、后编码：** 审核并遵守 `docs/IMPLEMENTATION_PLAN.md`，每轮只执行批准的 `prompts/XX_*.md` 阶段，不超前开发。
2. **先读再改：** 读源代码、检查依赖/运行环境/Git 状态；不得擅自清库、删卷、覆盖配置、重置 Git 历史。
3. **简单可维护：** 遵循现有技术栈，避免微服务和无关依赖；前端组件化，禁止嵌入原型 iframe 伪装完成。
4. **真实与可追溯：** 每条用户作答都有来源与可核验状态；`skipped` != `practiced`；没有 AI/ASR 就不生成虚构报告或分数。
5. **安全：** 所有密钥仅在服务端环境变量；本地无身份验证的服务不得暴露公网或局域网；原创内容要有来源/许可记录。
6. **测试：** 做了什么测什么，实际运行 lint/build/测试，未运行或失败必须直说。自动化浏览器测试之外的麦克风权限用手工验证清单补足。
7. **变更记录：** 每轮输出 `docs/progress/PHASE_XX.md`，列明改动、实测命令、结果、失败、风险和后续建议。报告完成后停止等待审核。

## 技术方向（可按已审核架构调整）

- Web：Next.js App Router / TypeScript / Tailwind CSS。
- API：Java 21 / Spring Boot / MySQL 8 / Flyway。
- 单机优先，不依赖 Redis、微服务、支付、账号体系和商业第三方教材资源。

## 质量红线

- 不能把点击/播放计为掌握，不能将语音识别准确率冒充发音评测。
- 不能凭空合成用户真实训练记录、模型回复或测试报告。
- 不能为修复端口冲突而停止其他项目服务、删除旧容器或更改系统全局依赖。
