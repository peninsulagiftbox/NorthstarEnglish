## 2. 推荐决策摘要

保留Java21/Spring Boot/MySQL/Flyway与Next App Router/TS/Tailwind，单体单用户本地。以不可变课版本为发布单位，现有Demo ID/事件/草稿/录音/作文/复习来源不迁走；新增段落、身份映射、可变题集、概念出现位置和教学计划。新内容经独立本地CLI校验、审校、apply与publish，启动应用不自动发新课或重置current。

不选择重建数据库/覆盖旧版、修改历史迁移、统一巨大JSON库、微服务/MQ、图数据库或工作流引擎：当前复合外键与事务已能承载最小模型，额外设施增加部署/恢复和验证成本。音频先HTMLAudioElement片段控制，暂不引入采样级音频引擎；教学自动化先规则与人工量规，不因尚无AI而阻塞。

## 3. 依赖与开发顺序

`10A-R复审批准 → 10B-1数据安全 → 单独审核 → 10B-2多课读取 → 单独审核 → 10B-3身份与发布 → 10C音频/题量 → 10D跨课知识 → 10E导入器 → 10F教学编排与报告验收`。

10B三个子阶段也分别审核，不能一次默认放行。每阶段单独变更范围、独立测试与报告，完成后停止等待审核。10B-1/2/3–D新增内容只允许隔离测试fixture，不建立个人学习库教材导入流程；测试由专用夹具写入隔离库，不要求10E尚未实现的CLI。新教材正文与录音导入不在这些批准的默认范围内，10F后仍需单独权利与内容批次审核。

### Phase 10B-1：数据安全（下一步候选计划，尚未执行）

- 输入：10A-R复审与本子阶段执行授权、固定源码/迁移候选hash、当前V008基线、备份/媒体清单与隔离资源条件。先只读确认目标身份和Flyway状态；未满足条件不执行DDL。
- 顺序：①核对环境/端口/路径及源DB/Flyway；②仅按授权停本项目写入并备份SQL+媒体，核验大小/hash；③恢复到新隔离V008副本并验证基线；④仅在副本执行候选新版本迁移并旧列逐值比较；⑤在另一隔离空库从V001初始化至同一目标版本；⑥副本中故障注入、恢复到新的隔离目标，旧版读/真实续学/重启验证；⑦汇总证据并停止。
- 候选DDL只覆盖本次批准的最小安全演练范围，按04的V009组拆号；不在本子阶段实现多课界面、发布业务或教材导入。对10B-2/3后续新增/改变的DDL必须再次走两条路径和相关恢复，不能沿用旧候选PASS。
- 交付：预检与备份/恢复说明、候选迁移及隔离演练证据（实施时才创建）、`docs/progress/PHASE_10B_1.md`；04第2.1节的六项证据包。
- Go：B01/B03实际PASS，旧行/媒体完整性100%可解释，失败恢复可运行；环境阻塞如实报告。No-Go：只评SQL、只备份不恢复、只测空库、部分DDL不明或任何未解释数据差异。
- 停止点：不迁移/切换现有个人学习库，不开始10B-2；报告后单独审核。

- 交付：至少两个不同教学重点的原创配置（覆盖四种册型的配置校验fixture，但不伪称四册课程已建）、闭环E2E、五层报告、迁移/备份恢复与容量实测、`PHASE_10F.md`。

## 4. 统一交付与停止条件

阶段输入必须包括上阶段审核与固定源码/内容基线；每阶段先定向检查，再执行相关编译/类型/单元/集成/浏览器与必要恢复，记录实际退出码。人工麦克风、其他浏览器、另机若缺条件则NOT VERIFIED；核心幂等/数据保全/恢复缺失必须No-Go。

每次报告列通过/未通过验收ID、原始日志/截图位置和影响，用户审核后才下阶段。不预先更改全局运行时，不清卷，不更换秘密，不把DDL失败当事务回滚。09-R历史证据永久保留。
