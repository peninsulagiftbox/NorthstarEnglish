# Phase 03｜桌面工作台设计与验收基线

日期：2026-10-21。适用范围：六页面、六 Tab 与课程浏览；以 `references/phase1/` 的首页、课文工作台、精听截图及详细规范为依据。采用 ui-design / ui-audit 流程，保留既定桌面原型方向；ui-taste 的营销页规则不适用于本学习工作台，未引入 UI 框架或素材依赖。

## 设计约定

用户任务：从真实 API 找到唯一原创课，选句查看本地预置讲解，在任务间切换并恢复浏览上下文。浏览和草稿不生成练习证据。

| 变量 | 值与用途 |
| --- | --- |
| 背景 / 表面 / 正文 | `#f5f7fa` / `#ffffff` / `#192740` |
| 辅助文字 / 边框 | `#687b96` / `#e2e8f0` |
| 主操作 / 侧栏 / 错误 | `#087f70` / `#101f35` / `#a32d2d` |
| 字体 | Arial、PingFang SC、Microsoft YaHei 系统回退；正文 14px / 1.7，课文 14px，标题 26–30px |
| 间距 / 形状 | 主要间距 8/12/16/24/35px；表面圆角 18px，控件约 10px；轻边框、轻阴影 |
| 布局 | 224px 侧栏，76px 顶栏与课内底栏；主区自适应，课文/助教约 2:1（参照原图略宽课文） |
| 窄屏 | 小于 980px 折叠助教，原生 dialog 抽屉；640px 以下导航换行、单列页面、播放器左边界归零 |
| 动效 | 无功能性动画；切换保留组件，减少焦点丢失，无需用动画表达状态 |

组件：按钮 / 卡片 / Message / EmptyState / Modal / Toast / Tab / 句子列表 / 助教 / 播放器容器。按钮含默认、hover、active、focus-visible、disabled；Tab 提供 selected、ArrowLeft/Right、Home/End；错误使用文字和 alert，状态不只靠颜色。弹窗约束焦点，Esc 关闭，返回开启按钮。正文不嵌套交互控件，不使用 iframe 或整块 innerHTML。

## 与原型的有意差异

1. 首页用“暂无记录 / 尚未开放”代替原型的完成数、写作数与固定侧栏进度，未接入报告 API 时不伪造统计。继续学习读取真实课程列表和 Java/MySQL 恢复点；没有恢复点时显示开始入口。
2. 四册均显示 catalog_only / 仅目录，不生成可点击的伪课次；原创 Demo 独立于四册。提示本地测试与来源/声音授权待审查。
3. 点击句子仅更新讲解，不触发播放。播放器只在课内固定展示 76px 容器，相关按钮禁用且说明 Phase 04；其他页面不展示无上下文的播放器。
4. 听写、精读、口语、写作与测验可导航；正式训练按阶段标明待开发。听写/写作文本只作本机草稿，不提供模拟评分或正式提交。
5. `!showEnglish` 或听写 Tab 时，同时隐藏正文、译文、助教知识点与播放器目标文本；DOM 控件和辅助标签不携带答案。课文 API 仍包含合法正文，这属于交互防剧透，并非考试保密隔离。
6. 浏览位置存入独立 `study_resume`；草稿按内容版本/任务/句子分键（写作按课），保留 localStorage，不提前实现 Phase 04 的正式草稿/outbox 协议。音频播放句与位置暂未产生，不保存伪时间轴。
7. 未知课由真实课程 API 404，页面显示明确错误与返回入口；客户端工作台页面外壳本身可能返回 HTTP 200。未知页面走 Next.js not-found。
8. 同版 Next.js 内置 webpack 构建替代当前环境持续失败的 Turbopack 辅助进程；不改依赖、版本和锁文件。

## 验收证据

运行命令、逐项状态、截图和修正记录统一见 `docs/progress/PHASE_03.md`。必须分别判断编译、行为和视觉证据，不声称像素级一致或完整 WCAG 合规。麦克风、ASR、音频引擎、练习提交、写作版本和报告统计不属于本阶段。


## Phase 04 增量与验收基线

继续保留224px侧栏、主区/助教布局与桌面76px播放器。原型的媒体与训练脚本没有进入运行时。

1. 句子行选择与独立播放按钮分开；正在播放的句子单独标识。底栏固定描述真实音源，即使正在查看其他句；盲听时所有展示面只显示句号。
2. 将速度和互斥播放模式放到底栏；A–B展开在底栏上方，显示真实本句秒数和边界说明，无伪波形。窄屏播放器允许换行，主区额外留底部空间。
3. 听写反馈按词序对齐，保留原文并列标准写法；错误以文字和颜色共同标识。答案只出现在当前已提交反馈，换句/换Tab重置反馈。课文和反馈暴露使用保守同版本标记，不据此生成能力指标。
4. 真实练习次数与本轮 not_started/in_progress/practiced/skipped/paused 分开；先编辑进入in_progress。跳过、暂停和播放不增加累计次数。
5. 听写草稿升级为IndexedDB先落地、MySQL乐观锁同步；多页冲突保留本机/服务端两份文本。写作草稿继续保持Phase03边界。
6. `/review`当前只展示真实错误及来源和重练入口；翻卡/评级/调度尚未开放。首页和报告文案不再断言没有作答记录，汇总功能仍留Phase08。

实际视觉检查、截图、交互通过项及未测平台统一见 `docs/progress/PHASE_04.md`；不将构建成功当作完整UI合规验收。

## Phase 05 增量

- 5 个词条与阅读题已存在于冻结内容包，本阶段通过版本化知识点/题目关系入库并提供 API；词性/语境说明存于后端知识点记录，不改写已发布包或 hash。不添加未经查证的音标、词形或专业词典资质。
- 阅读错答会在精读 Tab 自动聚焦并高亮第 6 句、同步右栏，再由显式入口跳到完整课文；保留当前反馈，避免跳 Tab 后看不到本次错误。收藏不代表掌握，也不自动生成错误来源；本阶段错误复习仍只是来源列表，调度留 Phase 07。
- 阅读累计作答与当前轮状态独立；浏览/收藏不生成 evidence，跳过/暂停不删除历史。听写逐句状态不被阅读完成覆盖。

## Phase 06

录音以私人本地磁盘+MySQL元信息持久化，IndexedDB仅作失败上传缓冲；未加密并明确告知，不延续原型刷新即丢失的正式存储方式。录音时锁定目标句和Tab，播放器禁用以避免录入示范音。客户端实际回放满250ms后自动记录观察事件，人工自评单独保存且不增加回放次数；数据标记client_reported_playback，不声称专业评测。

写作采用整段前后文本比较（增删配色），不伪称语法分析；历史不可变，回载需确认且仅更新草稿。无正式版本删除接口，录音删除有二次确认和墓碑。仅原创建议表达，不在提交前给完整范文。
