# Northstar English — Phase 1 桌面学习网站原型

这个包是个人学习第一阶段的交互演示，不是已经接入 AI 的商业产品。

## 先体验

1. 解压文件夹，安装并打开 Chrome。
2. 最简单：直接双击 `english_lab_desktop_prototype.html`，体验课文、播放、听写、词汇、写作和测验。
3. **推荐方式（录音与本地数据更稳定）**：打开终端，进入解压文件夹运行：

```bash
python3 -m http.server 8000
```

访问：`http://localhost:8000/english_lab_desktop_prototype.html`

如果 `8000` 端口已被占用，可改成 `8001`，并使用相应端口访问。

## 建议先试这条路径

- 首页 → 「开始第一节课」 → 点击对话句子播放。
- 切换「精听听写」，点第 6 句，输入错误答案，查看标准句对照和复习卡生成。
- 切换「精读词汇」，点击 `beside` 再回答阅读问题。
- 切换「口语跟读」，允许麦克风，录音并回放；录音失败可以「暂时跳过」。
- 切换「写作」，输入 2 句英文，保存 V1，再修改保存 V2。
- 切换「课时测验」，故意答错至少 1 题，再进入「智能复习」。
- 回首页查看阶段记录；浏览器本地存储可保存部分状态和文稿。

## 本包包含

- `english_lab_desktop_prototype.html`：完整可点击的离线 HTML 样机，内嵌原创短对话及合成音频，不依赖远程 CDN。
- `Northstar_English_Phase1_桌面Web详细设计与验收.md`：11 类页面规格、用户流程、实体/API、验收用例、四个开发迭代。
- `preview_home.png` / `preview_lesson.png` / `preview_listening.png`：桌面截图。

- 原创课程 The Neighborhood Garden 的文本及讲解专为此 Demo 编写，**没有复制《新概念英语》课文**。四册仅供课程框架设计，实际导入教材内容需确认使用许可。

- 已通过浏览器自动化验证主要导航、播放触发、听写错误生成复习、阅读题、跳过状态、作文、测验和复习交互。由于执行环境的浏览器安全策略限制，没有在真实 `localhost` 来源完整验证麦克风和刷新持久化；请在自己 Chrome 浏览器中实际测试。
