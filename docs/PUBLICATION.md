# 公开仓库范围与隐私检查

公开仓库包含 Phase01 工程骨架，以及本次用户授权按阶段提交的 Phase02 内容 API 和 Phase03 桌面工作台；同时包含自动化脚本、依赖/锁文件、设计规格和脱敏阶段报告。GitHub仓库公开可见，不代表部署了网站或公开了本地服务。

## 明确排除

- `.env`及本地环境变体，仅提交含占位值的`.env.example`；项目独立数据库随机密码不会上传。
- `.local/`中的JDK、下载、日志、进程记录和私有发布前备份；node_modules、Next/Maven构建产物、缓存。
- `docs/evidence/`、`output/`和Playwright状态/快照/追踪；这些证据可能包含本机路径、时间、容器或进程信息，继续留在本地供审核。
- 私人录音、数据库导出/备份、证书/私钥和个人IDE/助手配置；不删除本地文件或已有数据库卷。
- 原型HTML、内嵌合成音频及原型图片。音频生成来源和授权审查尚未完成，Phase01公开工程不依赖这些素材。

## 公开前检查

1. 显式暂存工程与文档，核对暂存文件清单、体积和`.gitignore`规则；不使用无差别`git add -A`。
2. 对暂存blob扫描：本地`.env`秘密值精确匹配、常见访问令牌/私钥模式、个人绝对路径、私人邮箱、连接串密码、禁止上传的文件/目录。仅报告命中文件与类型，不输出秘密。
3. 核对依赖锁文件没有内嵌认证信息，首个提交历史没有误入的日志、数据、证书、音频或本地配置。
4. Git作者/提交者使用已验证GitHub账号的noreply邮箱，配置只作用于此仓库，不修改全局Git身份。
5. 推送后复核远程仓库公开属性、默认分支和远程HEAD与本地提交一致。

公开文档已去除个人工作区绝对路径和无关项目环境清单。阶段报告保留真实通过/失败/未测结论；原始日志路径表示本地证据位置，不代表这些文件已公开。后续新增日志、截图或媒体须重新审核后才可纳入版本控制。

本次不新增开源许可证，避免代替所有者授予未指定的使用权；未来如选择许可证，再明确覆盖范围与第三方素材权利。

本轮用户授权将全部应入库代码按批次提交到GitHub。Phase10B新增的应用、测试、迁移、可复用审计/隔离工具、脱敏阶段报告及独立技术签收纳入版本控制；历史执行脚本快照、原始命令JSON/日志、数据库和媒体清单、私人备份、进程/容器运行快照及打包回执继续留在本地。新增 `.gitignore` 规则只排除这些运行证据，不删除本地文件，也不取消已有跟踪文件。
